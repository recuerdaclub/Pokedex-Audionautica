# Pokedex Audionautica 1.0.5

Corrección de sincronización Drive/Dropbox y ajustes de interfaz.

## Windows

- Instala `Pokedex Audionautica_1.0.5_x64-setup.exe` (NSIS) o el MSI equivalente.
- **Signing:** unsigned.

## Novedades

- **Fix sincronización local:** al importar desde Drive/Dropbox, la app ahora restaura loops en la carpeta local actual aunque la ruta guardada en la base de datos esté desactualizada.
- **Sincronizar Pokedex:** el botón de importación manual se renombró y se alineó a la derecha en Registros audionáuticos.
- **UI más limpia:** se eliminó la sección Ableton Places (redundante con la carpeta local).

## Known limitations

Sin APIs de nube: Drive/Dropbox son carpetas locales sincronizadas. Los archivos deben estar descargados en tu PC (Disponible sin conexión) antes de sincronizar.
