# Pokedex Audionautica 1.0.2

UI Pokedex, filenames musicales, preview seekable, y espejos Local + Drive (Dropbox opcional).

## Windows

- Instala `Pokedex Audionautica_1.0.2_x64-setup.exe` (NSIS) o el MSI equivalente.
- **Signing:** unsigned.

## Changes

- Nombre de app: **Pokedex Audionautica**.
- Skin Pokedex, temas persistentes (incluido blanco), pantalla completa llena el chasis.
- Farmeo exige carpeta local + Google Drive; Dropbox se sincroniza al agregarla.
- Preservación de nombres (solo se quita el timestamp de Ableton Consolidate).
- Player seekable en revisión; sin ticket = ignorar al farmear.

## Known limitations

Sin APIs de nube: Drive/Dropbox son carpetas locales sincronizadas. LOOP POKEDEX lee SQLite local, no indexa Drive solo.
